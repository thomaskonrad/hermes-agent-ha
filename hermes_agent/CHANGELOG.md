## 0.2.0

- Runs Hermes Agent 0.23.4 with its dashboard in the Home Assistant sidebar.
- New app icon and logo: the Hermes Agent artwork from the upstream project
  (MIT), replacing the previous picture. The Hermes version is unchanged.

## 0.1.0

- Runs Hermes Agent 0.23.4 with its dashboard in the Home Assistant sidebar.
- New version scheme. The app version is X.Y.Z and no longer copies the Hermes
  version. A new Hermes patch release or an app fix raises Z. A new Hermes minor
  release raises Y and resets Z to 0. The Hermes version is named in each entry.
- The version numbers used before this release are retired. Install 0.1.0.
- Upgrading over existing data has not been tested on a real installation yet.
  Read Hermes' release notes first, and make a backup before you update.
